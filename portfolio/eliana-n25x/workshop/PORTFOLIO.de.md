# N25X Learning & Creative Studio — Projektprofil

**Konzept und kreative Leitung:** Natalie Ragulina (Netaniya). KI-gestützte Entwicklung mit dokumentierten Entscheidungen und eigener Prüfung.

**Live-Demo:** https://n25x-learning-preview.onrender.com

Interaktive, offlinefähige Bildungs- und Kreativplattform mit einem konfigurierbaren 3D-Roboter, Mathematik, zehn Sprachkursen, Musik, Programmierübungen und selbstständigen Projekten.

Technologien: JavaScript, Three.js/WebGL, Web Audio, HTML/CSS, Service Worker, lokale Profildaten, Python, SQLite, HTTP/REST, Git und GitHub Actions. Die separate lokale Python/SQLite-Lernumgebung verbindet eigenen vertrauenswürdigen Python-Code mit einem echten HTTP-Server. Der Browserkurs nutzt begrenzte Lerninterpreter und isolierte Vorschauen.

Mein Beitrag: Produktidee, kreative Leitung, Lernziele, Auswahl von Lösungsansätzen, laufende Prüfung und Abnahmeentscheidungen. Die Implementierung entstand mit KI-Unterstützung. Die Live-Demo basiert auf einem vollständig automatisiert geprüften Kandidaten; physische Geräteprüfung, sprachliche Fachprüfung und endgültige Abnahme stehen noch aus. Keine Behauptung einer anerkannten beruflichen Zertifizierung.

## Русский перевод

**Концепция и творческое руководство:** Natalie Ragulina (Netaniya). Разработка с помощью ИИ, документированием решений и собственной проверкой.

Интерактивная офлайн-образовательная и творческая платформа с настраиваемым 3D-роботом, математикой, десятью языковыми курсами, музыкой, программированием и самостоятельными проектами.

Технологии: JavaScript, Three.js/WebGL, Web Audio, HTML/CSS, Service Worker, локальные профили, Python, SQLite, HTTP/REST, Git и GitHub Actions. Отдельная локальная среда Python/SQLite соединяет собственный доверенный Python-код с настоящим HTTP-сервером. Браузерный курс использует ограниченные учебные интерпретаторы и изолированные предпросмотры.

Мой вклад: идея продукта, творческое руководство, учебные цели, выбор решений, текущая проверка и решения о приёмке. Реализация выполнена с помощью ИИ. Демоверсия основана на кандидате, прошедшем автоматические проверки; физические устройства, экспертная проверка языков и окончательная приёмка ещё не завершены. Признанная профессиональная сертификация не заявляется.
