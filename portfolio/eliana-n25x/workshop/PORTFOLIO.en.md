# N25X Learning & Creative Studio

**Creator and product direction:** Natalie Ragulina (Netaniya). AI-assisted engineering and documented human review.

**Live demonstration:** https://n25x-learning-preview.onrender.com

N25X is an interactive, offline-capable educational and creative web application with a configurable articulated 3D mentor, mathematics, ten language courses, music composition, programming practice and independent engineering projects. The separate local Python/SQLite lab offers real HTTP, persistent data and an opt-in learner implementation.

## Demonstrable engineering

- Modular JavaScript, Three.js/WebGL, Web Audio, responsive CSS, local profile persistence, offline cache and standalone HTML.
- Bounded educational interpreters for JavaScript/Python and SQL practice, sandboxed HTML/CSS previews, local API/Git/review simulations.
- Data-connected project dashboard, independent learner tests and source/evidence export.
- Real loopback Python HTTP and SQLite lab, parameterized queries, validation, transactions, persistence, explicit local opt-in for learner code.
- GitHub Actions: unit tests, source/build verification, desktop and touch Chromium, real Python/SQLite HTTP tests and real local Git.

## Creator contribution

Original product concept and creative direction; educational requirements; selection and rejection of implementation approaches; ongoing review, testing and acceptance decisions. Implementation is AI-assisted, not a claim that all code was hand-written or independently authored by the creator.

## Demonstration guide

Open Learn, choose a course, complete an exercise, explore Programming, inspect the capstone data flow and export a verified project. The public demo is a local-first browser application; the separate Python lab requires a computer and local setup. Do not enter sensitive information.
