## Contribution classification
Human: original product concept, character and visual direction, feature priorities, scope changes, exclusions, user experience constraints, ongoing acceptance criteria and product decisions.
AI-assisted: code implementation, generated lesson material and translations, technical design details, test construction/execution and documentation drafting under the creator's direction. Later technical choices such as the exact review intervals are implementation decisions made by the assistant, not attributed to the owner as personally invented.
Joint process: iterative requirements, review, feedback, correction, and release decisions. Actual manual acceptance is recorded only when observed.
