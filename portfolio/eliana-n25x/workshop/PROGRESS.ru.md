Текущая ветка — `codex/n25x-learning-platform` в публичном `Netaniya/Netaniya`, каталог `portfolio/eliana-n25x`. Общий сборщик и остальные три проекта сохраняются. Главная страница проекта и инструкции: `../README.md`, `../README.en.md`, `../README.ru.md`. Текущий выпуск и браузерные результаты: `docs/eliana-n25x-workshop/publication.json` в корне репозитория. До подтверждённой публикации этот файл может описывать прежний выпуск; не переносить его результаты на новую сборку.

## Основные этапы

1. Исходный квест с изображениями и шестью главами сохранён по адресу `/eliana-n25x/`.
2. Управляемое 3D-приключение сохранено отдельно по адресу `/eliana-n25x/3d/`.
3. Robot Studio получает собственный адрес `/eliana-n25x/workshop/`: робот, обучение, творчество и поинты.
4. Добавлены тёмная тема, гуманоидные пропорции, материал/телосложение, пальцы и кинематика шага.
5. Добавлены реальное выполнение учебных программ, проверочные входы, викторина с функцией очков, самостоятельные HTML-проекты, десять начальных словарей и черновики каждого инструмента.
6. Для публикации добавлены видимый переключатель языка приложения в верхней панели, сведения о создателе, инструкции DE/EN/RU и скачивание всего Studio одним HTML-файлом.

## Сохранения и офлайн

Ключ Studio: `eliana-n25x.workshop.v1`. Новые поля добавляются с проверкой и значениями по умолчанию. Имя, приобретённые детали, поинты и проекты прежнего профиля сохраняются. Ключи старых игр: `eliana-n25x.save.v1` и `eliana-n25x.3d.v1`; Studio их не меняет.

Новая сборка содержит 30 обязательных ресурсов с проверкой SHA-256, включая скачиваемый `download/N25x-Studio.html`. Переносимая копия содержит 20 модулей, портрет только робота, шрифт и лицензии. Старое имя скачиваемого файла остаётся сетевым совместимым адресом. Копия не регистрирует service worker и не предлагает собственную PWA-установку. Для установки используется HTTPS-веб-версия. Профили разных браузеров/источников могут различаться; есть экспорт/импорт.

## Проверка

Автоматические тесты Node/linkedom/VM и симуляция кэша проверяют логику, модели, экспорты, совместимость профиля и локализацию. Они не заменяют реальный браузер. Отдельный Chromium-сценарий в `.github/workflows/eliana-workshop-browser.yml` проверяет компьютер и эмулированный телефон настоящими нажатиями, рендерит WebGL и сохраняет снимки/отчёт. Для новой версии сценарий должен закончиться успешно до обновления main.

Проверяются также видимый языковой переключатель, изменения текущего экрана без потери поинтов, все десять стартовых языков, викторина, скачанный HTML из локального файла без сети и холодная офлайн-перезагрузка. Состояние публикации фиксировать только по фактическим результатам Actions и HTTP-проверке байтов. Физические Android/iOS и установка на устройства владельца требуют отдельного прохождения.

## Границы возможностей

Учебный интерпретатор реализует ограниченную часть JavaScript; это не Python и не произвольный браузерный JS. Языковые курсы содержат 120 смысловых реплик на язык в 12 темах; это начальная практика, полный A1–C1 ещё не готов. Материалы подготовлены с ИИ-помощью, носители и преподаватели их пока не проверяли. Тексты проектов создаёт пользователь. N25x использует подготовленные локальные объяснения; свободного облачного ИИ-чата нет. Переписка, друзья и облачная синхронизация ещё не подключены. Денежная часть отсутствует.

Третьесторонние лицензии Manrope (SIL OFL) и Three.js (MIT) сохраняются. Личные исходные фотографии не публикуются. Изменения не затрагивают другие репозитории.
