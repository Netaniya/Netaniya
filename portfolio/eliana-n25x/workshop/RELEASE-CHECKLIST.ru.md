### Предварительный облачный просмотр
Подготовлен отдельный сервер на Node.js, который отдаёт только проверенные по SHA-256 файлы собранного Workshop. План: отдельный бесплатный сервис Render во Frankfurt, ручные деплои проверенных кандидатов. Не менять main или видимость репозитория. Для создания сервиса требуется подтверждение пространства My Workspace. Публичная ссылка не является защитой доступа; запрет индексации не делает её приватной. Профили локальны для каждого домена.

Комплексный Dashboard: учебная цепочка API → SQL → JavaScript → HTML/CSS теперь соединена через безопасную подстановку данных. Три сценария; проверка браузером и самостоятельный проект на реальном Python/SQLite остаются необходимыми.

Самостоятельная практика реального SQLite: незаполненный модуль ученика, отдельный эталон и семь групп тестов; запускаются локально. Проверка эталона добавлена в CI. Интеграция самостоятельного кода в HTTP-клиент/сервер и испытания новичком ещё необходимы.

Реальная локальная интеграция кода ученика с HTTP и SQLite реализована через --learner (только доверенный локальный Python, отдельная учебная база). Проверки добавлены; до подтверждения CI и ручной приёмки не считать завершённой.
