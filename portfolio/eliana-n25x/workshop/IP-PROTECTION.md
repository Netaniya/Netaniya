# N25X / ELIANA — protection plan
Creator: Natalie Ragulina (Netaniya), 28 November 2026.

## Applied
Rights notices in core source files, author metadata and offline package. Existing third-party licenses preserved. Build hashes cover the notice (integrity, not secrecy or legal ownership proof). Contribution logs distinguish human creative direction and AI-assisted work.

## Exposure and migration
Netaniya/Netaniya is public and contains multiple portfolio projects. Public GitHub code may be viewed and forked under its terms. Browser code and standalone HTML remain accessible. No copy blocker or watermark guarantees confidentiality; existing copies cannot be recalled automatically.

Recommended: separate private development repository, controlled review access, public portfolio teaser without core sources, server-side sensitive logic and authenticated access. Public client code remains accessible. Verify Pages and plan constraints before migration. No visibility, deployment or billing changes made.
