# N25X Git Lab

© 2026 Natalie Ragulina (Netaniya). All rights reserved for protected original project materials.

The browser lesson visualizes working file, staging, commits, branch switching and fast-forward merge. It is not Git itself. Run `python3 practice.py` on a computer with Git installed to execute the corresponding workflow in a temporary local repository. The script creates no remote, sends no data and cleans its temporary repository on exit. Use the printed commands as a reference when practicing in your own disposable repository. GitHub pull requests, authentication and remote operations are separate future lessons, not simulated here.
