Мобильное веб-приложение с оригинальным гуманоидным роботом: обучение, практика, собственные проекты и мотивирующие поинты. Код, иллюстрация робота, переводы и технические проверки подготовлены с помощью ИИ по решениям автора. В текущем Studio используется только робот N25x; прежние игры доступны отдельно как архивные версии.

## Попробовать

1. Вверху выбери язык интерфейса: Deutsch, English, Русский или Українська. При первом посещении включён немецкий.
2. Настрой своего 3D-робота; нажми на модель, чтобы увидеть движение суставов.
3. **Учиться → Математический практикум**: тема, объяснение, пример, самостоятельное решение, очередь ошибок и самопроверка на десять задач.
4. **Учиться → Языковые уроки**: выбери один из десяти языков, тему и режим чтения, письма или сборки предложения. Язык перевода выбирается отдельно.
5. **Учиться → Программирование**: исправь реальный код и проверь несколько входных значений.
6. **Создать → Пианино и композиция**: играй пальцами или клавишами A W S E D F T G Y H U J K, запиши аккорды, добавь дорожку, измени ноты, сохрани и скачай WAV или MIDI.

## Фактический объём

- Математика: **48 типов задач**, по 256 параметрических вариантов — **12 288 вариантов**. Есть объяснения и шаги решения. Классы обозначают сложность; полнота национальной школьной программы не подтверждена.
- Языки: **12 тем × 120 исходных смысловых реплик на каждом из 10 языков**, всего 1 200 переводных текстов. Три текстовых формы практики на реплику. Это начальные материалы, подготовленные с ИИ-помощью; проверки носителями ещё нет. **Полный путь до C1 пока не готов.**
- Немецкий, английский, грузинский, украинский, русский, китайский, испанский, французский, итальянский и японский. Грузинская, китайская и японская письменность сохраняется. Аудирование доступно при установленном локальном голосе устройства; записанной речи носителей в составе приложения нет.
- Программирование: **20 исполняемых миссий**, 95 нормальных и граничных входов, подсказки и объяснения. Ограниченный интерпретатор поддерживает числа, логику, условия, циклы и функции.
- Пианино: диапазон **A0–C8**, запись многопальцевых аккордов, до четырёх дорожек, 64 тактов и 2 048 нот; редактирование высоты, начала и длительности. Оригинальные синтезированные звуки пианино, баса и колокольчика. Экспорт MIDI, WAV и редактируемого JSON.
- Сохраняются викторины, истории с выбором, текстовые и другие творческие инструменты. Проекты и профиль можно переносить файлами. Поинты нельзя обменять на деньги.

## Установка и офлайн

Android/Chrome: меню → «Установить приложение». iPhone/Safari: «Поделиться» → «На экран Домой». На компьютере — установка через поддерживаемый браузер. Это устанавливаемое веб-приложение; публикация в магазинах приложений не выполнялась.

После первого онлайн-запуска дождись в ⚙ подтверждения проверки файлов. Service worker сверяет SHA-256 всех 30 обязательных ресурсов. Локальные голоса устройства — отдельная необязательная возможность; доступность зависит от устройства. Сохраняй резервный профиль: браузер может удалить локальные данные.

В ⚙ есть **«Скачать приложение в HTML»**: файл содержит весь код, робот, портрет робота, шрифт и лицензии. [Самостоятельная копия](https://netaniya.github.io/Netaniya/eliana-n25x/workshop/download/N25x-Studio.html). Современный браузер может открыть её без сети; телефонный просмотрщик файлов может не исполнять JavaScript. Профили сайта и локального файла могут различаться — используй экспорт/импорт.

## Для работодателя

ES-модули JavaScript, Three.js, Web Audio, собственные ограниченные интерпретаторы, адаптивный HTML/CSS, PWA, Node/linkedom/VM-тесты и GitHub Actions Chromium. Модели и синтез звука оригинальные. Свободный ИИ-чат, аккаунты, переписка, облачная синхронизация и платные API не подключены.

```sh
cd portfolio/eliana-n25x
npm ci --ignore-scripts
npm run build
npm run check
npm test
python3 -m http.server 8080 --bind 127.0.0.1 --directory workshop/dist
```

Открой `http://localhost:8080/`. В CI — Node.js 24. Из корня: `node scripts/build-pages.mjs` и `node --test tests/pages.test.mjs`. Браузерный сценарий проверяет компьютер и эмулированный телефон отдельно от автоматических тестов. Физические устройства и фактическая установка на них должны проверяться отдельно. Текущий выпуск: [publication.json](../../docs/eliana-n25x-workshop/publication.json).
