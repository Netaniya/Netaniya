Интерактивная учебная и творческая мастерская для телефона и компьютера. Пользователь собирает своего гуманоидного 3D-робота, практикуется и создаёт собственные небольшие проекты. Eliana и N25x — постоянные герои-наставники. Код, переводы, сгенерированные портреты и технические проверки разработаны с помощью ИИ по решениям и требованиям Natalie Ragulina.

## Как попробовать за три минуты

1. Сверху выбери **Язык приложения → Русский**. Доступны немецкий, английский, русский и украинский. При первом посещении включён немецкий; выбор сохраняется.
2. В разделе **Мой робот** задай имя, телосложение, панели и материал. Нажми на настоящую 3D-модель — робот помашет рукой.
3. Открой **Учиться → Программирование и практика**. Измени блок или код, запусти пример, затем нажми **Проверить все случаи**.
4. Открой **Создать → Моя игра-викторина**. Добавь свои вопросы, три разных ответа и правильный вариант. Проверь программу очков и нажми **Попробовать**.
5. Сохрани работу, скачай рабочий HTML для прохождения или JSON проекта для редактирования на другом устройстве.

## Что работает

- Оригинальный гуманоид с суставами, пальцами, материалами и освещением в тёмной мастерской.
- Пять практических заданий: переменные, условия, циклы, функции и поиск ошибки. Учебная часть JavaScript действительно исполняется ограниченным интерпретатором; результаты проверяются на нескольких входных значениях.
- Редактор викторины: 1–8 вопросов, своя функция начисления очков, игровой просмотр, экспорт HTML и проверяемый импорт JSON.
- Математика 11 уровней сложности, ежедневные задания, локальный разбор выражений и три программы движения по сетке.
- Десять изучаемых языков: немецкий, английский, грузинский, украинский, русский, китайский (путунхуа), испанский, французский, итальянский и японский. Пока по шесть слов: карточки, выбор и письмо. Это стартовые наборы, а не полные курсы. Язык занятий выбирается отдельно от языка интерфейса.
- Короткие задания по логике, физике, биологии, географии и цифровым навыкам с объяснениями.
- Двадцать направлений творчества: викторина, история с выбором, письмо, сообщение, сценарий, текст песни, стихотворение, статья, сцены комикса, открытка, веб-страница, чек-лист, таймер, карточки, значок, стикер, карта идей, план дня, мелодия и движения робота. Часть использует общий текстовый редактор. Тексты пишет пользователь; свободная генерация ИИ не подключена.
- Поинты за подтверждённый результат, детали робота, отдельные черновики, локальные сохранения и перенос профиля. Денежных выплат и платежей нет.
- Четыре языка интерфейса, крупные кнопки, оригинальные синтезированные звуки, громкость, отключение звука, веб-установка и HTML-копия.

## Как установить на телефон или передать другу

**Android / Chrome:** открой ссылку приложения в Chrome и выбери в меню **Установить приложение**. В некоторых версиях пункт находится внутри «Установить и создать ярлык».
**iPhone / Safari:** открой ссылку в Safari → **Поделиться → На экран «Домой»**. Если есть переключатель «Открывать как веб-приложение», включи его.
**Компьютер:** используй значок установки или пункт «Установить приложение» в поддерживаемом браузере.

Сначала зайди с интернетом и дождись в **⚙ Настройки** подтверждения проверки файлов. Только после этого эта копия готова работать без сети. Браузер может удалить локальное хранилище, поэтому важный профиль лучше экспортировать. Переписка и облачная синхронизация пока не подключены.

Чтобы передать **всё приложение одним файлом**, открой **⚙ → Скачать приложение в HTML**. В файл встроены программные модули, изображения, шрифт и лицензии. Его можно самостоятельно отправить другу и открыть в современном браузере. Простой просмотрщик файлов на телефоне может не запускать JavaScript. Это веб-приложение и отдельная HTML-копия, не APK и не публикация в магазине приложений. Сохранения веб-версии и файла могут различаться; профиль переносится экспортом и импортом.

## Для работодателя и технической проверки

Личный проект портфолио: JavaScript ES-модули, HTML/CSS, Three.js, Web Audio, Web App Manifest, отдельный service worker, Node-тесты и GitHub Actions. Во время работы не нужны CDN, аккаунт или платный ИИ-API. Трекинг не подключён. Математический помощник и подготовленные ответы N25x работают локально. Свободного ИИ-чата, действующей социальной сети и полных школьных программ сейчас нет.

```sh
cd portfolio/eliana-n25x
npm ci --ignore-scripts
npm run build
npm run check
npm test
python3 -m http.server 8080 --bind 127.0.0.1 --directory workshop/dist
```

Затем открыть `http://localhost:8080/`. В CI используется Node.js 24; Python здесь нужен только как необязательный локальный HTTP-сервер. Общая сборка портфолио: `node scripts/build-pages.mjs` из корня репозитория. [Техническое описание](workshop/README.en.md), [проверки](../../docs/eliana-n25x-workshop/README.ru.md), [браузерный сценарий](../../.github/workflows/eliana-workshop-browser.yml).

Автоматические проверки логики/DOM/кэша, настоящее прохождение Chromium и физические устройства учитываются отдельно. Текущая публикация и версия записаны в [publication.json](../../docs/eliana-n25x-workshop/publication.json). Эмуляция мобильного экрана не означает проверку на реальном Android/iPhone.
