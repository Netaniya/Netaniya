## Для чего нужен проект

Лаборатория сравнивает два варианта ответа и показывает, какие критерии выполнены и где допущены ошибки. Ответы можно изменить, провести проверку заново и скачать воспроизводимый отчёт.

## Что работает

- Выбор отдельных тестов или групп.
- Восемь тестовых случаев: структура JSON, категория обращения, сумма, дата, параметры предполагаемого вызова инструмента, отсутствие данных, удаление адреса электронной почты и посторонняя инструкция в документе.
- Два редактируемых варианта ответа.
- Реальная серверная проверка правил с результатами каждого критерия.
- Частичные баллы, вес теста и общая взвешенная оценка.
- Время Мюнхена, таймер выполнения и прогресс завершённых проверок.
- Скачивание JSON-отчёта с ответами, выбранными тестами, результатами, временем и версией проверяющего кода.
- Повторный расчёт отчёта отдельной программой на Python.
- Сохранение в браузере, если браузер его разрешает. Без локального хранения сравнение и экспорт продолжают работать, а интерфейс сообщает об отсутствии сохранения.
- Немецкий при первом открытии, английский, русский и украинский. Сам тестовый набор остаётся на немецком.
- Компактный интерфейс, карточки тестов на узких экранах и ограниченные анимации хода проверки.

## Как считается оценка

Каждое правило получает 0 или 1. Балл теста — доля выполненных правил. Общая оценка — среднее баллов тестов с учётом их весов. Тест считается полностью пройденным только при выполнении всех его правил.

В исходных примерах вариант A проходит **4 из 8** тестов и получает **51,28%**, вариант B — **7 из 8** и **84,62%**. Это оценки составленных примеров, а не результаты сравнения настоящих моделей.

## Реальная техническая реализация

Веб-приложение: **JavaScript Worker, HTML, CSS, JavaScript, localStorage**.

**Python** — отдельный воспроизводимый проверяющий модуль, который запускается локально. Сайт не работает на Python/FastAPI. Автоматические проверки сопоставляют результаты Python и JavaScript, включая невидимые Unicode-пробелы и ограничения длины ответа.

## Что работодатель может проверить

Можно увидеть открытые критерии, изменить ответ и проверить изменение оценки. Код и тесты позволяют обсудить проверку структурированных данных, качество ответов, объяснение ошибок, работу серверного API и воспроизводимость результатов.

## Честные границы

**ИИ-модель не подключена.** Варианты A и B — вручную составленные учебные примеры. Приложение не генерирует новые ответы и не выполняет реальные действия через инструменты.

Измеряется время проверки правил и полное время запуска, включая сетевые запросы. Задержка и стоимость ИИ-модели не выдумываются и не показываются как измеренные.

Восемь случаев не являются полноценным исследованием качества моделей. Фиксированные правила не оценивают все смысловые ошибки, все атаки или общие способности ИИ. В проекте нет коммерческих пользователей, серверной базы пользовательских данных или системы учётных записей сотрудников.

## Проверки и вклад

Подтверждены **32 автоматических проверок** и успешные проверки GitHub: расчёт оценок, ошибочные данные, языки, сохранение, несколько окон, сбой связи, экспорт отчёта, запуск скачанных Python-файлов и повторное вычисление результата. Проверки интерфейса с имитацией DOM не заменяют визуальную проверку в браузере. Опубликованный вид для компьютера просмотрен; отдельный мобильный визуальный прогон пока не выполнен.

Мой вклад: выбор направления второго проекта, требования к четырём языкам, часам и анимации, просмотр первоначального оформления на телефоне и конкретные требования к переработке типографики и расположения элементов. ИИ-ассистент реализовал код, автоматические тесты, исправления и публикацию в рамках нашей совместной разработки.

## Локальная проверка

Из папки `portfolio/ai-quality-lab`, Node.js 22+ и Python 3.10+:

```sh
npm run build
npm test
npm run validate
python3 python/evaluator.py --output report.json
python3 python/evaluator.py --input exported-report.json --output replay.json
```

Можно также скачать с сайта `evaluator.py` и `fixtures.json` в одну папку и выполнить `python3 evaluator.py`. Отчёт пересчитывается из ответов и выбранных тестов, а не копируется из прежней оценки.

Это учебная работа, а не коммерческая клиентская рекомендация.

## React / TypeScript и FastAPI

[Отдельная запускаемая реализация](fullstack/README.ru.md): React-клиент, Python/FastAPI API, те же критерии проверки и необязательная генерация через серверный Responses API. 17 проверок API и 8 проверок клиента прошли. Реальный запрос к модели пока не проверен. Публичная Worker-демонстрация сохраняет прежний режим с учебными примерами.

## Четыре полных тестовых набора
Название, задание, примеры ответов и языковые правила соответствуют выбранному языку. В отчёте указаны язык и набор данных; скачивается выбранный языковой набор. Пользовательские ответы сохраняются. После смены языка нужно заново запустить сравнение. Python и JavaScript дают эквивалентные результаты во всех четырёх языках.
