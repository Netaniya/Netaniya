# Портфолио Natalie Ragulina (Netaniya)

Два опубликованных учебных проекта, разработанных совместно с ИИ. Оба открываются без входа. Исходный код, правила работы и проверки доступны на GitHub.

| Проект | Назначение | Опубликованные технологии |
| --- | --- | --- |
| [AI Request Desk](portfolio/ai-request-desk/README.ru.md) | Обработка обращения, сопоставление счёта, редактирование ответа и проверка человеком | JavaScript, HTML, CSS, localStorage |
| [AI Quality Lab](portfolio/ai-quality-lab/README.ru.md) | Проверка сохранённых ответов по правилам, сравнение вариантов и воспроизводимый отчёт | JavaScript Worker, HTML, CSS, отдельный Python-модуль |

## Открыть и проверить

**AI Request Desk:** [демо](https://ai-request-desk-neta26.wellolm4.chatgpt.site). Пример DEMO-104 показывает расхождение между 179 € из обращения и 149 € из учебного реестра. Пользователь меняет черновик, подтверждает проверку и одобряет результат. Подтверждены 17 автоматических проверок и проверка основного сценария владельцем на телефоне.

**AI Quality Lab:** [демо](https://ai-quality-lab-neta26.wellolm4.chatgpt.site). Пользователь запускает сравнение восьми случаев, просматривает правила, меняет ответы и скачивает отчёт. Отчёт можно пересчитать в Python. Подтверждены 23 автоматические проверки; отдельная визуальная проверка на телефоне остаётся незавершённой.

## Что подтверждено этими проектами

Рабочие учебные сценарии, открытый код, обработка ошибок, сохранение состояния, четыре языка интерфейса, автоматические проверки и публикация демонстраций. Проекты дают материал для обсуждения требований, интерфейсов, рабочих процессов, проверки данных и разработки с помощью ИИ.

## Границы и роль автора

В обоих проектах **нет подключённой ИИ-модели**. Первый использует демонстрационные правила обработки обращений, второй проверяет сохранённые учебные ответы. Веб-версия второго работает на JavaScript; Python используется отдельно для воспроизведения проверок.

Мой вклад — постановка задач, выбор направления и требований, решения об интерфейсе и языках, проверка основного сценария первого проекта и замечания к оформлению второго. Реализация кода и автоматических тестов выполнена ИИ-ассистентом. В этих описаниях не заявляется самостоятельное написание всего кода.

Проекты подтверждают учебную практику в указанном объёме. Опыт коммерческой эксплуатации и работа с другими технологиями оцениваются отдельно. Эти приложения дают материал для обсуждения кода и выполнения практической задачи.
